# Функции

Функция — это соответствие между двумя множествами, при котором каждому элементу первого множества ставится в соответствие ровно один элемент второго.

## Основные понятия

- **Область определения (Д(f))** — все допустимые значения аргумента $x$
- **Область значений (Е(f))** — все принимаемые значения функции $y$
- **График функции** — множество точек $(x; f(x))$ на координатной плоскости
- **Нули функции** — значения $x$, при которых $f(x) = 0$ (пересечение с осью Ox)
- **Интервалы знакопостоянства** — где $f(x) > 0$ или $f(x) < 0$

---

## Элементарные функции

### 1. Линейная: $y = kx + b$
- График: прямая
- $k > 0$ — возрастает, $k < 0$ — убывает

### 2. Квадратичная: $y = ax^2 + bx + c$
- График: парабола
- Вершина: $x_0 = -\frac{b}{2a}$, $y_0 = f(x_0)$
- Ветви вверх ($a>0$) / вниз ($a<0$)

### 3. Обратная пропорциональность: $y = \frac{k}{x}$
- График: гипербола
- Две ветви, симметричны относительно начала координат
- Асимптоты: $x=0$, $y=0$

### 4. Корень: $y = \sqrt{x}$
- Область определения: $x \ge 0$
- График: полупарабола, лежащая на боку

### 5. Показательная: $y = a^x$
- $a > 0, a \neq 1$
- Проходит через $(0; 1)$
- $a > 1$ — возрастает, $0 < a < 1$ — убывает
- Асимптота: $y = 0$

### 6. Логарифмическая: $y = \log_a x$
- Обратная к показательной
- Область определения: $x > 0$
- Проходит через $(1; 0)$
- Асимптота: $x = 0$

### 7. Тригонометрические
- $y = \sin x$, $y = \cos x$ — период $2\pi$, область значений $[-1; 1]$
- $y = \tan x$ — период $\pi$, асимптоты в $\frac{\pi}{2} + \pi k$

## Свойства функций

| Свойство | Описание |
|----------|----------|
| **Чётность** | $f(-x) = f(x)$ — график симметричен относительно Oy |
| **Нечётность** | $f(-x) = -f(x)$ — график симметричен относительно начала координат |
| **Периодичность** | $f(x+T) = f(x)$ — наименьшее $T > 0$ — период |
| **Монотонность** | Возрастает/убывает на интервале |
| **Экстремумы** | Максимумы и минимумы |

## Производная

### Определение
$$f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

### Геометрический смысл
- Тангенс угла наклона касательной к графику в точке
- Скорость изменения функции

### Таблица производных
| $f(x)$ | $f'(x)$ |
|--------|---------|
| $C$ | $0$ |
| $x^n$ | $n x^{n-1}$ |
| $\sqrt{x}$ | $\frac{1}{2\sqrt{x}}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\frac{1}{\cos^2 x}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\frac{1}{x}$ |
| $\log_a x$ | $\frac{1}{x \ln a}$ |

### Правила дифференцирования
- $(u \pm v)' = u' \pm v'$
- $(uv)' = u'v + uv'$
- $(\frac{u}{v})' = \frac{u'v - uv'}{v^2}$
- $(f(g(x)))' = f'(g(x)) \cdot g'(x)$ — производная сложной функции

## Исследование функции по производной

1. Найти область определения
2. Найти производную $f'(x)$
3. Найти критические точки: $f'(x) = 0$ или $f'(x)$ не существует
4. Определить знаки производной на интервалах (метод интервалов)
5. $f'(x) > 0$ — функция возрастает, $f'(x) < 0$ — убывает
6. Переход $+ \to -$ — максимум, $- \to +$ — минимум
