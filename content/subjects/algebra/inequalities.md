# Неравенства

Неравенство — математическое выражение, связывающее два выражения знаком неравенства ($<$, $>$, $\le$, $\ge$).

## Линейные неравенства

### Определение
Линейное неравенство с одной переменной:
$$ax + b > 0 \quad (\text{или } <, \ge, \le)$$

### Свойства
1. Можно прибавлять/вычитать одно число от обеих частей
2. Можно умножать/делить обе части на **положительное** число (знак не меняется)
3. При умножении/делении на **отрицательное** число **знак меняется** на противоположный

**Пример:**
$$3x - 6 > 0$$
$$3x > 6$$
$$x > 2$$

**Пример с отрицательным:**
$$-2x + 4 \le 10$$
$$-2x \le 6$$
$$x \ge -3 \quad (\text{знак изменился!})$$

## Квадратные неравенства

### Алгоритм решения
1. Найти корни соответствующего уравнения $ax^2 + bx + c = 0$
2. Отметить корни на числовой прямой
3. Определить знаки интервалов (парабола вверх/вниз)
4. Выбрать нужные интервалы с учётом строгости неравенства

**Пример:** $x^2 - 5x + 6 > 0$

Корни уравнения: $x_1 = 2$, $x_2 = 3$
Парабола ветви вверх ($a=1>0$)

```
    +        -        +
---(2)-------(3)-------
```

Ответ: $x \in (-\infty; 2) \cup (3; +\infty)$

**Пример:** $-x^2 + 4x - 3 \ge 0$

Корни: $x_1 = 1$, $x_2 = 3$
Парабола ветви вниз ($a=-1<0$)

```
    -        +        -
---(1)-------(3)-------
```

Ответ: $x \in [1; 3]$

## Системы неравенств

Решается каждое неравенство отдельно, затем находится пересечение множеств решений.

**Пример:**
$$\begin{cases}
x + 2 > 0 \\
2x - 4 \le 6
\end{cases}$$

1) $x > -2$
2) $2x \le 10 \Rightarrow x \le 5$

Пересечение: $x \in (-2; 5]$

## Неравенства с модулем

### Основные свойства
- $|x| < a \Leftrightarrow -a < x < a$ (при $a > 0$)
- $|x| > a \Leftrightarrow x < -a$ или $x > a$ (при $a > 0$)
- $|x| \le a \Leftrightarrow -a \le x \le a$
- $|x| \ge a \Leftrightarrow x \le -a$ или $x \ge a$

**Пример:** $|x - 3| < 5$
$-5 < x - 3 < 5$
$-2 < x < 8$
Ответ: $x \in (-2; 8)$

## Дробные неравенства

### Метод интервалов
1. Перенести всё в левую часть, привести к общему знаменателю
2. Найти нули числителя и знаменателя
3. Отметить на числовой прямой (нули числителя — закрашенные/пустые точки, нули знаменателя — **всегда пустые**!)
4. Определить знаки на интервалах
5. Выбрать подходящие интервалы

**Пример:** $\frac{x-2}{x+1} \ge 0$

Нули: $x = 2$ (числитель), $x = -1$ (знаменатель — **ИСКЛЮЧЕН**)

```
    +        -        +
---(-1)-------(2)-------
     ○         ●
```

Ответ: $x \in (-1; 2]$

## Типовые ошибки

| Ошибка | Правильно |
|--------|-----------|
| Умножение на выражение с переменной без учёта знака | Использовать метод интервалов |
| Забывание про ОДЗ (знаменатель $\neq 0$) | Всегда исключать нули знаменателя |
| Неправильная работа с модулем | Запомнить свойства или раскрывать по определению |

## Подготовка к ОГЭ/ЕГЭ

**ОГЭ:** Линейные, квадратные, простые системы, метод интервалов
**ЕГЭ профиль:** Неравенства с модулем, параметрические, логарифмические, показательные, тригонометрические

> 💡 **Совет:** Всегда рисуй числовую прямую и отмечай точки — визуально меньше шансов ошибиться!
