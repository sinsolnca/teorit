# Грамматика

Грамматика — раздел языкознания, изучающий структуру языка: морфологию (слова) и синтаксис (предложения).

## 1. Морфология (части речи)

### Независимые части речи

| Часть речи | Вопрос | Признаки | Примеры |
|------------|--------|----------|---------|
| **Существительное** | кто? что? | Род, число, падеж, склонение | стол, книга, радость |
| **Прилагательное** | какой? чей? | Род, число, падеж, степень сравнения | красивый, мой, лучший |
| **Числительное** | сколько? который? | Составное/простое, количественное/порядковое | пять, пятый, оба |
| **Местоимение** | указывает на предмет | Личные, притяжательные, указательные, неопределённые | я, мой, этот, кто-то |
| **Глагол** | что делать? что сделать? | Вид, время, наклонение, число, лицо | читать, читаю, прочитал |
| **Наречие** | как? где? когда? куда? | Не изменяется, обстоятельство | быстро, вчера, очень |
| **Причастие** | какой? что делающее? | Признак действия, род/число/падеж, залог, вид | читающий, прочитанный |
| **Деепричастие** | что делая? что сделав? | Признак действия, не изменяется | читая, прочитав |

### Служебные части речи
- **Предлог** — связывает слова в предложении (*в, на, под, за, из, к, о, от, перед, при, через*)
- **Союз** — связывает однородные члены или части сложного предложения (*и, а, но, или, что, чтобы, если, когда*)
- **Частица** — придаёт оттенок смысла (*не, ни, бы, же, ли, вот, даже, только*)
- **Междометие** — выражает эмоции (*ой, ах, ух, эй, ура*)

## 2. Морфологический разбор (план)

### Существительное
1. Ч.р. — существительное, означает предмет, отвечает на вопрос *кто/что?*
2. Нач.ф. — И.п. ед.ч. (кто/что?)
3. Пост.призн.: собств./нариц., одуш./неодуш., род, склонение
4. Непост.призн.: число, падеж
5. Синт.р. — подлежащее/дополнение/обстоятельство

### Прилагательное
1. Ч.р. — прилагательное, означает признак предмета, вопроса *какой/чей?*
2. Нач.ф. — И.п. ед.ч. м.р. (какой?)
3. Пост.призн.: кач./относит./притяж.
4. Непост.призн.: полн./кр. форма, род, число, падеж (в полн.ф.), степень сравн.
5. Синт.р. — определение/сказуемое (в кр.ф.)

### Глагол
1. Ч.р. — глагол, означает действие/состояние, вопрос *что делать/сделать?*
2. Нач.ф. — неопр.ф. (что делать?)
3. Пост.призн.: несов./сов. вид, переход./непереход., возвр./невозвр., спряжение
4. Непост.призн.: наклонение, время (в изъяв.), число, лицо (в изъяв. наст./буд.), род/число (в усл./прош.)
5. Синт.р. — сказуемое

## 3. Синтаксис

### Предложение
Грамматическая единица, выражающая законченную мысль.

**По цели высказывания:**
- **Повествовательные** — сообщают факт (*Я иду домой.*)
- **Побудительные** — призывают к действию (*Иди домой!*)
- **Вопросительные** — содержат вопрос (*Ты идёшь домой?*)

**По интонации:**
- **Невыразительные** (точка)
- **Выразительные** (восклицательный знак)

### Члены предложения

#### Главные
| Член | Вопрос | Выражается | Подчёркивание |
|------|--------|------------|---------------|
| **Подлежащее** | кто? что? | Сущ. в И.п., местоим., числ., инфинитив | одна линия |
| **Сказуемое** | что делает? чем занимается? | Глагол, связка + существительное/прилагательное | две линии |

#### Второстепенные
| Член | Вопрос | Выражается | Подчёркивание |
|------|--------|------------|---------------|
| **Дополнение** | случая? (р.п.) и др. | Сущ. в косвенных падежах | пунктир |
| **Определение** | какой? чей? | Прилаг., причастие, местоим., сущ. в р.п. | волнистая |
| **Обстоятельство** | где? куда? когда? как? почему? | Наречие, дееприч., сущ. с предлогом | точечно-пунктир |

## 4. Виды предложений по структуре

| Вид | Описание | Пример |
|-----|----------|--------|
| **Двусоставное** | Есть подлежащее и сказуемое | *Солнце светит.* |
| **Односоставное** | Только одно главное membro | |
| — Назывное | Только подлежащее (сущ. в И.п.) | *Вечер. Тишина.* |
| — Определённо-личное | Сказуемое в 1/2 л. ед.ч. наст. | *Иду домой.* |
| — Неопределённо-личное | Сказуемое в 3 л. мн.ч. наст./буд. | *Стучат в дверь.* |
| — Безличное | Нет подлежащего, не может быть | *Светает. Мне холодно.* |
| — Инфинитивное | Сказуемое — инфинитив | *Цель — победить.* |

---

## 5. Сложные предложения (кратко)

| Тип | Союз/связь | Пример |
|-----|------------|--------|
| **ССП** | И, а, но, да, или | *Дождь шёл, но мы шли.* |
| **СПП** | Что, который, где, когда, если | *Я знаю, что ты придёшь.* |
| **БСП** | Без союзов (интонация) | *Солнце село — наступила ночь.* |

## 6. Гомонимы частей речи (важно для ЕГЭ/ОГЭ)

| Пара | Различие |
|------|----------|
| **Наречие / Предлог** | *вокруг (наречие) — вокруг дома (предлог + р.п.)* |
| **Наречие / Сущ. с предлогом** | *вдали (наречие) — вдали (вдали = в дали? нет) → вдали (наречие) vs в дали (предл. + сущ.)* |
| **Союз / Наречие** | *так (союз) — так (наречие = таким образом)* |
| **Частица / Союз** | *же (частица) — же (союз = и)* |
| **Причастие / Прилагательное** | *воспитанный (причастие: воспитанный родителями) — воспитанный (прилагательное: воспитанный человек)* |

## 7. Типовые задачи ОГЭ/ЕГЭ

### Морфология (ОГЭ №3-5, ЕГЭ №5-8)
- Определить часть речи
- Указать морфологические признаки
- Найти форму слова
- Выбрать правильное написание формы

### Синтаксис (ОГЭ №6-9, ЕГЭ №15-19)
- Определить тип предложения
- Найти грамматическую основу
- Расставить знаки препинания
- Сделать синтаксический разбор

## Шпаргалка: Степени сравнения прилагательных/наречий

| Положительная | Сравнительная | Превосходная |
|---------------|---------------|--------------|
| **Простая** | | |
| красивый | красивее / более красивый | самый красивый / красивейший |
| быстро | быстрее / более быстро | самый быстро / быстрейше |
| **Сложная** | | |
| хороший | лучше | лучший |
| плохой | хуже | худший |
| большой | больше | наибольший / величайший |
| маленький | меньше | наименьший / малейший |
| много | больше | наибольший |
| мало | меньше | наименьший |

> 💡 **Совет:** На экзамене всегда **определяй часть речи по вопросу и морфологическим признакам**, а не по значению! Слово «чтение» — это существительное (что? чтение), а не глагол.
